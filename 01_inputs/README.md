# Raw inputs

This directory contains original-source data only. The three-city source subsets are under `demo/raw/`, with provider fields, source geometry or native raster pixels preserved. See [source coverage and provenance](demo/raw/README.md).

Processed city grids, resident population, building floor area, place layers, kernel settings, routing graphs and hourly location shares are under `04_intermediate/demo/stage_2/`. Daily activity allocation results are under `04_intermediate/demo/stage_3/`. The final population and functional land-use products are under `05_outputs/demo/`.

See [example data](demo/README.md) for the data products and [processing stages](../02_code/README.md) for their calculation.
