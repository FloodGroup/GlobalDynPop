# Time-use source materials

These files contain public source tables/publications used as evidence for the country parameters. They are not respondent-level survey diaries. All spatial reconstruction inputs are under the other folders of this city.

- Japan: original STULA 2016 published activity and location workbooks (Statistics Bureau of Japan).
- Finland: the archived Eurostat HETUS activity table; EXPOLIS values are a clearly labelled transcription of the published table, not participant records.
- World Bank: original observation fields for this country, subset from the archived API response, used for school-age population and enrolment.
- HAPEM-MS3: original EPA Appendix A; Baltimore demographic groups supply the adopted outdoor-duration weights.

The full hourly location-share construction additionally uses cross-country activity/location mappings, donor day-type curves and survey diaries subject to their provider access conditions. The harmonised matrices and fitted distance-decay parameters remain adopted study inputs; these public files alone do not reproduce all survey harmonisation or parameter fitting.

(2007), doi:10.1038/sj.jes.7500490; Glen and Shadwick (1998), EPA HAPEM-MS3. See per-file source records for exact roles and selection operations.
