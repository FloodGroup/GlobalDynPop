# Example source data

`raw/` contains original-source subsets for Helsinki, Kitakyushu and Takasaki-Maebashi. It includes buildings, places, urban-centre boundaries, native-grid GHSL population/volume/height, transport features, land-use evidence and water features. The [source guide](raw/README.md) records coverage, providers and extraction operations.

All processed layers are in [Stage 2 intermediate data](../../04_intermediate/demo/stage_2/README.md). Attractiveness, destination population and in-transit population are in [Stage 3 intermediate data](../../04_intermediate/demo/stage_3/README.md). Final files are described in the [output dictionary](../../05_outputs/README.md).
