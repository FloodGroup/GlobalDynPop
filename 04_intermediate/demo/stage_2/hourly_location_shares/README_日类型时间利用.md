# 工作日与休息日的逐时活动地点份额（GlobalDynPop-100m）

每个国家、每种日类型一张表：24 行（当地时间 0–23 时）× 7 类地点，每行之和为 1。七类地点为：

- residential（住宅，C1）
- commercial_industrial（工作与商业，C2）
- education（教育，C3）
- medical_public（医疗与公共服务，C4）
- leisure（文化、体育与休闲，C5）
- transportation（出行途中，C6）
- other（其他，C7）

模型通过 `code/gdp/timeuse.py` 的 `daytype_shares(iso3, daytype)` 读取，按 `daytype_index.csv` 查文件。本文件夹由 `code/timeuse_daytype/day-type profile construction` 从第一阶段的表（`data/timeuse/daytype/`）生成；方法的完整说明见 `docs/` 中方法说明第 6 节。

## 文件

| 文件 | 内容 |
|---|---|
| `<ISO3>_workday.csv`、`<ISO3>_restday.csv` | 工作日、休息日（周末与公共假日） |
| `<ISO3>_saturday.csv`、`<ISO3>_sunday.csv` | 有分日数据的国家另给周六、周日（73 国） |
| `<ISO3>_alldays.csv` | 平均日 |
| `daytype_index.csv` | 153 个模型国家 × 日类型对应的文件、来源（method 列）、借用国和地区 |
| `daytype_sources.csv` | 有本国分日类型数据的国家所用的调查、周末定义和日记数 |
| `school_floor.csv` | 学龄儿童修正：在学的 5–14 岁人口占比 E、修正前的教育峰值和补入量 |
| `lunch_correction_log.csv` | 午间修正：每张表 12、13 时去掉的在家份额 |
| `../daytype/variants/` | 第一阶段文件夹中午间修正前的原表（`*.uncorrected.csv`，只用于比较，模型不读） |

## 来源

1. **出行日志（3 国）**（`code/timeuse_daytype/travel_diary.py`）：美国 NHTS 2017（5 岁以上，一周七天）、墨西哥城都会区 EOD 2017（全部家庭成员；工作日、周六；周日 = 周六 × NHTS 的"周日/周六"比）、圣保罗都会区 Pesquisa OD 2017（全年龄；工作日；休息日 = 工作日 × EOD 的"休息日/工作日"比）。按 10 分钟步长跟踪每位受访者，个人权重加权后按小时平均。
2. **本国时间利用调查（19 国）**（`build_daytype.py` 及各 `src_*.py`）：
   - 含地点变量的日记：加拿大 GSS 2022、英国 UKTUS 2014–15、西班牙 EET 2009–10、阿尔巴尼亚 2010–11、南非 2010、加纳 2009、尼日利亚 2024、巴基斯坦 2007、印度 2019（城镇）；
   - 公布的分时段表：日本社会生活基本调查 2016、韩国生活时间调查 2024、秘鲁 ENUT 2024、比利时（MTUS 时段分布加 2013 年分日类型总量）；
   - 本国分日类型日总量加参照国时段分布（日总量约束路径）：澳大利亚、哥伦比亚、摩洛哥、巴拉圭、俄罗斯；
   - 中国：国家统计局 2018 年时间利用调查公报的工作日、休息日分钟数，作用于 城镇平均日基线，时段取蒙古、韩国、日本三国平均，属于估计。
3. **其余 131 国：本国平均日加借用的日类型对比**（`make_transfer.py`）：保留本国平均日基线矩阵 L_X（平均日基线表中没有的 9 国用借用国平均日），只借用同地区借用国的日类型对比：

   ```
   r_dt(h, l) = 借用国平均 [ L_d,dt(h, l) / L_d,平均日(h, l) ]
   L_X,dt = L_X × r_dt，每小时归一
   ```

   | 地区 | 借用国 |
   |---|---|
   | 北美 | 美国、加拿大 |
   | 拉美 | 墨西哥、哥伦比亚、秘鲁、巴拉圭 |
   | 西欧 | 英国、西班牙、比利时 |
   | 东欧与中亚 | 俄罗斯、阿尔巴尼亚 |
   | 东亚 | 日本、韩国、中国 |
   | 南亚 | 印度、巴基斯坦 |
   | 东南亚 | 中国、印度 |
   | 中东北非 | 摩洛哥 |
   | 撒哈拉以南非洲 | 加纳、尼日利亚、南非 |
   | 大洋洲 | 澳大利亚 |

   借用国的比值由其时间利用调查表计算；美国和墨西哥用的是 2025 年美国时间利用调查（ATUS）和墨西哥全国分日类型总量加借用时段的表，使全部比值来自同类来源。平均日基线表中没有的 9 国为吉布提、几内亚比绍、拉脱维亚、巴布亚新几内亚、巴勒斯坦、塞拉利昂、塞尔维亚、多哥、特立尼达和多巴哥。

## 两项修正

- **午间修正**（`lunch_correction.py`，在 `make_transfer.py` 之后运行）。地点由活动推断的表格把用餐都算在家里，中午在家份额凸起 10–18 个百分点。含地点变量的 10 个日记调查（上述 9 个与美国 ATUS）中午在家份额与 11 时到 14 时的连线相差都在 ±0.5 个百分点以内（西班牙更低，午餐在 14 时）；首尔的逐时手机网络人口（KT、SK Telecom）中，居住区在中午持续变空、中心区持续变满。做法：受影响表格的每种日类型，12、13 时的在家份额降到 11 时与 14 时的连线（只降不升），降下的份额按各外出类别在同一连线下的午间缺口分回（主要是工作和教育）。出行日志不做这项修正。工作日 12 时去掉的份额：泰国 18.4、越南 18.3、印度尼西亚 17.1、菲律宾 16.9、韩国 14.9、日本 13.9、法国 10.8、中国 7.6 个百分点；共 64 张工作日表超过 0.5 个百分点。
- **学龄儿童**（`day-type profile construction` 的 `school_floor`）。多数调查只含 10 岁或 15 岁以上的人。工作日教育份额的峰值低于在学的 5–14 岁人口占比 E = s₅₋₉·小学入学率 + s₁₀₋₁₄·(小学 + 中学入学率)/2（世界银行 WDI，最近年份；缺失时取地区中位数）时，差额按本国教育时段从在家移到教育，每小时在家份额至少保留 5%；休息日不变，平均日重算为 5/7 工作日 + 2/7 休息日。出行日志国家不改。150 国中 127 国补入（补入量中位数 0.074）。

## 注意

- **哪天是休息日**由各国日历决定：多数国家是周六、周日，许多中东国家是周五、周六（伊朗为周五）。表格只区分工作日与休息日，不规定是星期几。
- **共同模式**：休息日 13 时在外的人比工作日少约三分之一，工作与商业地点的份额约减半，休闲份额约增加一倍。
