# Figure data

This directory contains plotting data, source metadata and numerical checks. Documentation images are stored separately in `06_docs/figures/`.

- `w_indoor/`: city parameter values and coordinates, country income observations, the climate display grid, geographic context, source metadata and figure checks. See the [indoor-share guide](../w_indoor.md).
- `population_visualization_metadata.json`: source hashes and colour-scale settings for the population maps.
- `time_use_weights_metadata.json`: source matrices and checks for the hourly-share figure.
- `provenance.json`: provenance of the documentation figures.
